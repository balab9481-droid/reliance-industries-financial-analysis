# Reliance Industries Financial Analysis

## Project Overview

This project presents a financial analysis of Reliance Industries Limited (RIL) using data from the company's annual report.

The analysis focuses on financial performance, year-over-year (YoY) growth, and key financial ratios.

## Objectives

- Analyze the financial performance of Reliance Industries.
- Compare financial data across financial years.
- Calculate and interpret key financial ratios.
- Analyze year-over-year (YoY) growth.
- Understand the company's debt and equity position.

## Financial Analysis

The project includes:

- Revenue analysis
- Profit analysis
- Total Debt
- Total Equity
- Financial ratio analysis
- YoY growth analysis

## Key Ratios

The following financial ratios are analyzed:

- Current Ratio
- Debt-to-Equity Ratio
- Net Profit Margin
- Return on Equity (ROE)
- Return on Assets (ROA)

## Tools Used

- Microsoft Excel
- Annual Report Data
- Financial Statement Analysis

## Data Source

The financial information used in this project was collected from the official annual report of Reliance Industries Limited.
